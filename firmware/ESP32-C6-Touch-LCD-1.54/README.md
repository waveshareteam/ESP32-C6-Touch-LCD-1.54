# ESP32-C6-Touch-LCD-1.54 Firmware

[中文](README_ZH.md)

This directory contains prebuilt examples and demos for the touch model. To restore the original demo, see the [factory firmware guide](../README.md).

| File | Purpose |
| --- | --- |
| [`01_button_example.bin`](01_button_example.bin) | Button example |
| [`02_qmi8658_example.bin`](02_qmi8658_example.bin) | QMI8658 IMU example |
| [`03_sd_card_test.bin`](03_sd_card_test.bin) | TF card test |
| [`04_lvgl_example.bin`](04_lvgl_example.bin) | LVGL example |
| [`05_esp-brookesia.bin`](05_esp-brookesia.bin) | ESP-Brookesia demo |

See the [product documentation](https://docs.waveshare.com/ESP32-C6-Touch-LCD-1.54) for flashing instructions.
