# Waveshare ESP32-C6-Touch-LCD-1.54

[中文](README_ZH.md)

The ESP32-C6-Touch-LCD-1.54 is a compact development board built around the ESP32-C6 (single-core 32-bit RISC-V processor up to 160 MHz, 16 MB Flash), with 2.4 GHz Wi-Fi 6, Bluetooth 5 LE, and IEEE 802.15.4 connectivity for Zigbee and Thread. It integrates a 1.54-inch 240 × 240 capacitive touch LCD, a QMI8658 six-axis IMU, audio output, a TF card slot, USB Type-C, three user buttons, and battery support, making it suitable for LVGL interfaces, portable devices, smart home controls, and other IoT applications.
